# LLM-generated (qwen2.5-coder-14b-instruct via LMStudio)

Synthetic ATT&CK technique records generated by the qwen2.5-coder-14b-instruct-uncensored model running locally via LMStudio. Each record was generated at temperature 0.4 against a category-specific prompt with few-shot examples.

## What it's used for

Fills gaps in deterministic synthetic coverage; some duplication and quality issues have been documented.

## How it's ingested

The records in this directory are produced by
`scripts/stamp_and_reorg.py`, which reads from
`data/datasets/buckets/<bucket>/` and writes here.

To re-run: `uv run python scripts/stamp_and_reorg.py`
