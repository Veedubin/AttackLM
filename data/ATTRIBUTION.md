# Data Attribution

All training data in this directory is a *transformation* of upstream
open-source security projects with permissive open-source licenses.

For the complete per-source attribution, license analysis, and
re-distribution guidance, see
[**/ATTRIBUTION.md**](../ATTRIBUTION.md) at the repository root.

For a bucket-level breakdown, see
[**/data/datasets/buckets/ATTRIBUTION.md**](datasets/buckets/ATTRIBUTION.md).
